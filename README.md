# Fulfil.pro — сайт

Редизайн сайта фулфилмент-оператора Fulfil.pro: главная, страницы Wildberries,
Ozon, Яндекс Маркета, модели FBS и политика конфиденциальности.
Статическая вёрстка без сборки: HTML, CSS, ванильный JS.

**Перенос в Тильду идёт через пульт:**
<https://ivanweb1.github.io/fulfil-landing/tilda/out/COPY.html> — он копирует код
блоков по кнопке, показывает SEO-поля страницы и помнит уже перенесённое.
Как устроен — в [tilda/README.md](tilda/README.md).

## Структура

- `index.html` — разметка страницы
- `wildberries.html`, `ozon.html`, `yandex-market.html`, `avito.html`, `fbs.html` — страницы направлений
- `tarify.html` — страница тарифов (`/tarify/`): прайс по вкладкам, квиз, этапы работы, FAQ
- `fbo.html` — фулфилмент по модели FBO (`/fulfilment-po-modeli-fbo/`): тарифы, квиз, таблицы маркетплейсов и сравнения FBO/FBS/DBS
- `upakovka.html` — упаковка товаров для маркетплейсов (`/upakovka-tovarov-dlya-marketplejsov/`)
- `dostavka.html` — доставка товаров на маркетплейсы (`/dostavka-tovarov-na-marketplejsy/`): площадки, схемы FBO/FBS, тарифы по пяти вкладкам, квиз, требования к приемке, FAQ
- `dostavka-wb.html` — доставка до склада Wildberries (`/dostavka-do-sklada-wildberries/`): склады, прайс по складам, калькулятор рейса (`calc-wb.js`, цены — в `window.WB_CALC` на странице), FAQ
- `about.html` — о компании (`/about/`): цифры, команда (слоты под фото и имена), клиенты, склад, гарантии, реквизиты
- `contacts.html` — контакты (`/contacts/`): карточки связи, карта Яндекса, как добраться, экскурсия и форма, юрданные; LocalBusiness в JSON-LD
- `terms.html` — условия использования (`/terms/`): 10 разделов с липким содержанием; дата редакции — заглушка `[дата публикации]`, заполняет клиент
- `styles.css` — стили
- `script.js` — слайдер первого экрана, квиз, аккордеон FAQ, формы
- `forms.js` — маска телефона и валидация с подсказками у полей (страница Авито; подключается до `script.js`)
- `assets/` — логотипы маркетплейсов и клиентов, фотографии склада
- `wildberries.html`, `ozon.html`, `yandex-market.html`, `fbs.html` — страницы направлений
- `privacy-policy.html` — политика обработки персональных данных
- `tilda/` — сборка страниц в Vibe-блоки Тильды и пульт переноса
- `parked/` — отложенный вариант блока тарифов (редакционный прайс-лист)

## Локальный просмотр

```
python -m http.server 4191
```

Затем открыть http://127.0.0.1:4191
